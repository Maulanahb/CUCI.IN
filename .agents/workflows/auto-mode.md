# Workflow: auto-mode

When invoked:
1. Scan prompt requirements against global and project skills.
2. Load relevant `SKILL.md` using `view_file`.
3. Announce `🎯 [Skill: <name>]`.
4. Execute with Caveman principles: high density, code first, zero fluff.
5. Verify output (tests/lint) before completion.
